# Agents with LangGraph

## Project Overview

`agents-with-langgraph` is a modular framework that leverages **LangChain**, **LangGraph**, and **Groq** to orchestrate specialized AI agents for common software development tasks. The system includes agents for:
- Documentation generation and maintenance
- Release note creation
- Issue management
- Code review

These agents are coordinated by a central GitHub coordinator agent, which delegates tasks via LangGraph tools. The architecture makes it easy to extend the framework with additional agents or integrate with other services.

## Installation

```bash
# Clone the repository
git clone https://github.com/your-username/agents-with-langgraph.git
cd agents-with-langgraph

# Create a virtual environment (requires Python >=3.12)
python -m venv .venv
source .venv/bin/activate  # On Windows use `.venv\Scripts\activate`

# Install the package and its dependencies
pip install -e .
```

The project relies on the following key dependencies (see `pyproject.toml`):
- `langchain`
- `langchain-community`
- `langchain-core`
- `langgraph`
- `langchain-groq`
- `pygithub`
- `tiktoken`

Make sure you have a valid **Groq API key** and a **GitHub token** set in a `.env` file (see `sample.env`).

## Usage Example

The entry point for the coordinator agent is `src/workflow/main.py`. A simple way to run the full workflow is:

```bash
python -m src.workflow.main
```

When executed, the coordinator will prompt the documentation agent (or any other sub‑agent) to perform the requested task. For example, to generate and commit updated documentation:

```python
from src.agents.graph import github_agent

response = github_agent.invoke({
    "messages": [{"role": "user", "content": "Create a documentation and raise a PR for it."}]
})
print(response)
```

The agents will use the provided tools to read files, write updates, and open a pull request via the GitHub API.
